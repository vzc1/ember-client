# Your mods

Drop Fabric mod `.jar` files for **Minecraft 26.2** in this folder (on GitHub: **Add file → Upload files**).
Every change here starts a new build, and the mods are baked into the game.

- Mods need Fabric, not Forge/NeoForge.
- Mods written in Kotlin (they depend on `fabric-language-kotlin`) are not supported yet.
- If a mod also needs other mods, add those too (or list them in `fabric/mods.txt`).
- Check the build's bake report (draft release "Latest build" → `logs.zip` → `bake-report.txt`)
  to see what applied and what had to be switched off.
